# Mohammad Saad — Personal Portfolio

Personal portfolio website for **Mohammad Saad**, Full-Stack Developer & AI/ML Engineer specialising in AI-powered web applications and business automation tools.

## Architecture & Principles
- **Frameworkless:** Built with native semantic HTML5, modern vanilla CSS, and clean JavaScript. No npm build steps, compilers, or external bundlers required.
- **Deployment:** Zero-config deployment via GitHub Pages or Vercel by hosting the root directory.
- **Performance & A11y:** Accessible design using semantic structures, strict color contrast, visible focus states, and native `@media (prefers-reduced-motion)` respect.
